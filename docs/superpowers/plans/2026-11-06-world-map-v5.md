# World Map V5 Implementation Plan

Goal: improve the opt-in World Map with original PS1 chibi glTF actors, state-aware animation and ambient scenery without changing controls or gameplay.

Architecture: GLTFLoader loads two same-origin, self-contained assets once per map layer; rigid-node animation clips run through AnimationMixer. Original procedural models provide immediate fallback. Authoritative state still controls all destinations; animation only interpolates presentation. All animation shares the existing 24 FPS visibility-aware loop.

Constraints: direct main updates explicitly authorized; no PR/branch, server edits, new buttons, gallery numbering invention, or external proprietary assets. Keep Phaser board/fallback, camera projection and 360° gestures. Android hardware validation must be distinguished from automated checks.

Design decision: use original rigid-joint glTF, not external rigs or skinned/high-poly models: compact downloads, predictable silhouettes, no texture/decoder dependencies. Preserve character color and immutable mission launchTile. Generate assets reproducibly from a source model builder. Environment uses bounded transform animation; no added realtime lights/shadow maps.

1. Actor animation: tests first for motion states, settling, return origin, persistent instances, asynchronous load/disposal. Add model builder, glTF generation, GLTFLoader asset library and actor transitions. Idle/walk/run/search/return clips share a stable node contract. Avatar moves around perimeter rather than across island. Robot remains at state-derived destination between ticks.
2. Environment: test deterministic bounded tree sway, waterfall particles, beacon rotation and cleanup. Integrate into existing loop with reduced-motion support and zero per-frame vector allocations in actor updates.
3. Verification and handoff: smoke, complete unit suite, TypeScript/build; inspect mobile rendering if browser access permits. Document limitations and reproduction instructions. Commit all changes atomically to latest main using expected-SHA lease. Check GitHub CI and production assets independently; never equate CI with Cloudflare deployment.

Review focus: late asset completion after disposal; state removal during loading; hidden-tab resume; rapid state transitions; settled robot locomotion and avatar perimeter route.
